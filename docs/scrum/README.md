# docs/scrum/

**Responsable:** Scrum Master

Documentos del proceso Scrum:

- Product backlog
- Sprint backlog y planificación de cada sprint
- Notas de las reuniones diarias (dailies)
- Sprint review y retrospectivas
- Definición de "hecho" (Definition of Done)

Sugerencia: una carpeta por sprint (`sprint-1/`, `sprint-2/`...).
Ejemplo de nombres: `product-backlog.xlsx`, `retrospectiva-sprint-1.pdf`.
